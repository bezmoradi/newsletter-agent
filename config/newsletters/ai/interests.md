I build software with AI coding agents and want to keep up with how that practice is changing. I care most about:

- Agent skills: how skills, plugins and instructions are written, packaged and shared for coding agents such as Claude Code.
- Harness engineering: the code, prompts, tools and checks around a model that make an agent reliable.
- Software factories and "dark factories": pipelines where agents take work from spec to shipped code, and how humans review, test and trust that output.
- Coding agents in practice: Claude Code, Codex, Gemini CLI and similar tools, with real workflows, failure stories and measured results.
- Context engineering: what goes into an agent's context, memory, retrieval and long-running tasks.
- Agentic workflow patterns and multi-agent orchestration, including evaluations of agents.
- MCP and tool design for agents.
- Durable execution for agents, such as Temporal.
- Go, when the article is about building agents or developer tools with it.

I care less about model benchmark announcements, funding news, general AI policy, consumer chatbot features and beginner tutorials, unless they change how coding agents are built or used.
